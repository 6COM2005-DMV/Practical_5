# Practical 5: Association Mining

6COM2005 Data Mining and Visualisation

## Aims
- Represent transactions as a one-hot (0/1) table.
- Write your own functions for support, confidence, and lift.
- Run the Apriori algorithm with `mlxtend` and create association rules.
- Mine a real dataset of 14 963 shopping baskets and judge which rules are useful.

## Files
- `Practical_5_T.ipynb`: the notebook you complete
- `6COM2005_DMV_Practical_5.docx`: the handout with all tasks
- `small_baskets.csv`: the 8 baskets from Lecture 5
- `groceries.csv`: 38 765 purchased items from a grocery store (member, date, item)
